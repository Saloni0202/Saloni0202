#### 🏢 1. PropIQ — AI-Powered Commercial Property Intelligence

An AI-powered commercial real estate analytics platform combining rental price prediction with document-based question answering.

**Key highlights**
- Processed and cleaned property data, reducing 1,910 raw records to 1,766 usable records.
- Compared Ridge Regression, Random Forest, and Gradient Boosting using cross-validation and held-out evaluation.
- Achieved **R² = 0.967**, with MAE of **$2.65** and RMSE of **$3.96** on the reported evaluation set.
- Built a TF-IDF-based retrieval pipeline over 125 property, lease, and market documents, achieving **98% Hit@1 across 75 labelled questions**.
- Developed a FastAPI application with rent prediction, document Q&A, portfolio analytics, and source citations.

**Tech:** Python · Scikit-learn · TF-IDF · RAG · FastAPI · Docker

#### 🛣️ 2. RoadSight AI — Pothole Detection & Road Condition Analytics

A computer vision application that detects potholes in road images and displays annotated predictions with confidence scores.

**Key highlights**
- Trained and evaluated a YOLO11n object detection model using a 3,000-image subset of a 13,767-image Kaggle dataset.
- Achieved **84.6% precision**, **75.0% recall**, and **82.6% mAP@50** on the reported evaluation.
- Built an interactive Streamlit interface for image-based inference.
- Displayed annotated detections, confidence scores, inference time, and an adjustable confidence threshold.

**Tech:** Python · YOLO11n · PyTorch · OpenCV · Streamlit

#### 📚 3. Agentic Document Intelligence Platform

An AI-powered document assistant that allows users to upload text documents, retrieve relevant information, and use tools through a conversational interface.

**Key highlights**
- Supports `.txt` and `.md` document uploads.
- Uses ChromaDB to store document chunks and retrieve relevant context.
- Integrates document search and calculator tools into an agent workflow.
- Supports rule-based tool routing for offline use and optional Claude-powered tool calling when an API key is configured.
- Provides a React frontend and FastAPI backend.

**Tech:** Python · FastAPI · React · ChromaDB · RAG · LLM Tool Calling
