### 🚀 Featured Projects

#### 🏢 [PropIQ — AI-Powered Commercial Property Intelligence](https://github.com/Saloni0202/PropIQ-AI-powered-Commercial-Property-Intelligence)

[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit-16a34a?style=flat-square)](https://propiq-bkvn.onrender.com/)

A commercial property analytics application combining data processing, machine learning-based rent prediction, and document question answering.

- 📊 Cleaned 1,910 raw property records into 1,766 validated records using Pandas and SQL.
- 🤖 Compared Ridge, Random Forest, and Gradient Boosting models, achieving an \(R^2\) score of 0.967 with the selected model.
- 🔎 Built a TF-IDF-based retrieval pipeline over 125 documents, reporting 98% Hit@1 across 75 labelled questions.

**Tech:** Python · Pandas · SQL · Scikit-learn · TF-IDF · FastAPI · Docker

#### 🚧 [RoadSight AI — Pothole Detection & Road Condition Analytics](https://github.com/Saloni0202/AI-Powered-Pothole-Detection-and-Road-Condition-Analytics)

[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit-16a34a?style=flat-square)](https://ai-pothole-detection.streamlit.app/)

A computer vision application that detects potholes in road images using YOLO11n.

- 🧠 Trained and evaluated a detector on a 3,000-image subset of a 13,767-image dataset.
- 📈 Achieved 82.6% mAP@50 and 57.3% mAP@50–95 on the reported evaluation.
- 🖥️ Built an interactive Streamlit demo with annotated predictions, confidence scores, and inference time.

**Tech:** Python · YOLO11n · PyTorch · OpenCV · Streamlit

#### 📚 [Agentic Document Intelligence Platform](https://github.com/Saloni0202/Agentic-document-intelligence-platform)

A document assistant that combines semantic retrieval with tool calling to answer questions about uploaded files.

- 📄 Supports `.txt` and `.md` document uploads through a React and FastAPI application.
- 🔍 Uses ChromaDB to store document chunks and retrieve relevant context.
- 🧮 Integrates document search and calculator tools, with offline rule-based routing and optional Claude-powered tool calling.

**Tech:** Python · FastAPI · React · ChromaDB · Anthropic Claude API
